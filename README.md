# PhysicsLab3

Упрощённая 2D-физика прямоугольников без вращения на C++17 и SFML 3.1.0.
Реализованы дискретный режим Primitive, swept AABB CCD и Multi-rate с группами
slow, medium, fast и stationary. При базе 60 Гц движущиеся группы обновляются
на 60, 120 и 240 Гц. Пороги скорости: 250 и 1000 px/s. Масса 0 означает
неподвижное тело с нулевой обратной массой.

## Сборка

Windows x64, Visual Studio 2022 с компонентом **Desktop development with C++**
и Windows SDK. Открыть `Physics.sln`, выбрать **Release / x64**, выполнить Build.
При наличии MSBuild в Developer PowerShell можно собрать командой:

```powershell
msbuild Physics.sln /p:Configuration=Release /p:Platform=x64
```

Внешняя зависимость SFML 3.1.0 для Visual C++ 2022 x64 загружается проектом
с официального сайта в `vendor`, если SDK отсутствует. При первом восстановлении
нужен доступ к сети. DLL копируются к программе автоматически.
Результат сборки: `build/x64/Release/Physics.exe`.

## Управление

- **A** — создать под курсором физический квадрат 32x32.
- **W** — начать неподвижную стену в позиции курсора; двигать мышью для
  изменения прямоугольника; повторное **W** фиксирует второй угол.
- **Esc** — отменить создание стены.
- Левая кнопка мыши — захватить тело; движение мыши задаёт скорость;
  отпускание сохраняет инерцию броска.
- **Pause / Resume** — остановить или продолжить симуляцию.
- **Physics** — частота базового физического шага, 15–240 Гц.
- **Playback** — отдельное замедление/ускорение виртуального времени, 0.1–4x.
- **Primitive / Sweep (CCD) / Multi-rate** — выбрать алгоритм.
- **Snapshot**, **Save**, **Load** — имя, сохранение и восстановление сцены.
  В поле работают Ctrl+A, Ctrl+V и редактирование текста.

## Сцены

Файлы находятся в `snapshots`. Для загрузки ввести имя без `.txt`.
Подробности: `snapshots/LAB_SCENES.txt`, формат: `snapshots/README.txt`.

- `lab01_primitive60`, `lab01_ccd60`, `lab01_multirate60`,
  `lab01_primitive240` — одинаковый снаряд 8x8 со скоростью 2000 px/s
  и стенка 10 px. Показывают туннелирование и отскок.
- `lab02_many_*` — 20 обычных тел, 3 быстрых, 3 внутренних препятствия,
  4 границы.
- `lab03_stack_*` — три стопки по пять тел, постоянная сила вниз.
- `lab04_timing_*` — контролируемая нагрузка для измерений.

Снапшот хранит положение, размеры, массу, скорость, силу, видимость и настройки
сцены в редактируемом текстовом формате. Перед сравнением алгоритмов нужно
заново загрузить начальное состояние.

## Измерения и проверки

```powershell
.\Run-Benchmarks.ps1
```

Собирается отдельная Release-программа и выполняются четыре варианта,
по три повтора на 50 секунд виртуального времени. Результаты:
`output/benchmarks/<дата_UTC>/report.md`, `summary.csv`, `runs.csv`, `input-scene.txt`.
Измеряется физика без рендеринга при расписании 120 виртуальных кадров/с.
Это не измерение полного кадра или FPS. Методика и параметры: `BENCHMARKS.md`.

Проверки экспорта и расписания:

```powershell
.\tests\BenchmarkTests.ps1
```

После Release-сборки в **x64 Native Tools Command Prompt for VS 2022**:

```bat
tests\Run-ReportValidation.cmd
```

Эта проверка повторяет расчёт снаряда и два прогона many/stack по 3000 шагов.
Пишет `output/report-data/validation.json`. Остальные C++-проверки находятся
в `tests/PhysicsTests.cpp`, `SceneTests.cpp`, `CCDScenesTests.cpp`.

## Ограничения

Нет вращения и трения; коэффициент восстановления равен 1.
CCD использует прямолинейную траекторию после обновления скорости базового
шага, перебор всех пар и лимит 128 контактов. При исчерпании лимита остаток
шага замораживается. Multi-rate удерживает позиции медленных тел между
их обновлениями и остаётся дискретным методом. Повторяемость проверяется
внутри одной сборки и платформы.

ChatGPT использовался для оптимизации написания кода, изучения темы
и оформления отчёта.
